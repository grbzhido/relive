## Deploy to GitHub Pages

1. Create a new repository on GitHub named `relive`
2. Push this directory:
   ```bash
   cd /path/to/relive
   git init
   git add .
   git commit -m "Initial commit: Relive landing page"
   git branch -M main
   git remote add origin https://github.com/grbzhido/relive.git
   git push -u origin main
   ```
3. Go to **Settings → Pages** in your repository
4. Set **Source** to `Deploy from a branch`, select `main` branch, and click **Save**
5. Your site will be live at `https://grbzhido.github.io/relive/` within a few minutes
